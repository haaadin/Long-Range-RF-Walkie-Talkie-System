# Long-Range RF Walkie-Talkie System

Design and analysis of an RF-based walkie-talkie circuit for long-range wireless communication.

## Overview
- Transistor-based RF stages and audio signal processing
- Circuit schematic with an RF amplifier, oscillator, modulation and audio processing sections
- Components: 555 Timer, RF transistors
- Studied the design requirements for long-range communication: RF transmission, reception, frequency tuning and antenna considerations

## Tools Used
LTspice, Transistor, 555 Timer

- `schematic/` : circuit schematic (image/PDF)
- `simulation/` : LTspice files (.asc)
- `README.md`
